# Assets — Bear Glasgow Dental

Drop your files into the appropriate subfolder:

## /logos
- `fdhs-logo.png` — Primary logo (recommended: PNG with transparent background, min 400px wide)
- `fdhs-logo-white.png` — White/reverse version for dark backgrounds
- `fdhs-logo-favicon.png` — Square icon version (512×512px) for favicon/app icon

## /images
- `og-sedation-dentistry.jpg` — Social share image (1200×630px recommended)
- `fdhs-office.jpg` — Exterior or interior office photo
- `fdhs-team.jpg` — Team/staff photo
- `sedation-nitrous.jpg` — Nitrous oxide procedure photo
- `sedation-oral.jpg` — Oral sedation / patient comfort photo
- `sedation-iv.jpg` — IV sedation photo
- `sedation-general.jpg` — General anesthesia / surgical photo
- `patient-consultation.jpg` — Doctor-patient consultation photo
- `hero-background.jpg` — Hero section background (1920×1080px recommended)

## /content
Drop any additional content files here:
- PDFs (patient forms, brochures, aftercare instructions)
- Videos (`.mp4` format preferred)
- Any other media assets

---

**Image format tips:**
- Photos → `.jpg` (smaller file size)
- Logos / icons with transparency → `.png`
- Simple graphics/icons → `.svg` (best for logos)
- Target file size: under 200KB per image for fast load times
